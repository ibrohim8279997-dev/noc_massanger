# ADR-001: объём криптографии и ML-DSA

Статус: принято владельцем.

Решение: протокол как у Signal. PQXDH (X25519 + ML-KEM-1024) и Double Ratchet через libsignal. Подписи внутри протокола классические (Ed25519/XEdDSA). ML-DSA из liboqs применяется только для подписи действий суперадмина, вне протокола libsignal.

Причина: в libsignal нет ML-DSA; встраивание в протокол означало бы свою обвязку вокруг библиотеки и повышало риск ошибок.

Последствия: подписи сообщений не квантово-устойчивы. Это принятый компромисс; пересмотр возможен позже отдельным решением.
