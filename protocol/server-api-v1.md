# Серверный API v1 (этап 1)

Кодирование: base64url без паддинга. Идентификаторы ящиков 16 байт, токены 32 байта, ключи устройств Ed25519 (32 байта).

## Подпись запросов устройства
Заголовки: `x-key` (pubkey), `x-ts` (unix, допуск ±60 с), `x-nonce` (16 байт, одноразовый), `x-sig`.
Подписывается: `"NOC1\n" + METHOD + "\n" + path + "\n" + ts + "\n" + nonce + "\n" + SHA256(body)`.
Любая ошибка даёт одинаковый `401`.

## Конечные точки
| Метод и путь | Доступ | Назначение |
|---|---|---|
| POST /v1/admin/bind | токен привязки | привязка суперадмина, токен одноразовый, 5 неудач блокируют до перезапуска |
| GET /v1/admin/users | суперадмин | список |
| PUT /v1/admin/users/{pub} | суперадмин | добавить пользователя (роль `user`) |
| DELETE /v1/admin/users/{pub} | суперадмин | удалить, каскадно: ящики, пакеты, префикс-ключи |
| PUT /v1/prekeys | устройство | непрозрачный пакет prekey + одноразовые |
| GET /v1/prekeys/{pub} | устройство | забрать пакет + один одноразовый (удаляется) |
| POST /v1/mailboxes | устройство | создать ящик (id, токен чтения; хранится SHA-256 токена) |
| DELETE /v1/mailboxes/{id} | токен ящика | удалить |
| POST /v1/mailboxes/{id}/packets | устройство | положить конверт ровно 16384 байта |
| GET /v1/mailboxes/{id}/packets | токен ящика | забрать (заголовок `x-mailbox-token`) |
| DELETE /v1/mailboxes/{id}/packets/{pid} | токен ящика | подтвердить и удалить |
| WS /v1/ws | токен ящика | сигнал «есть новое», без содержимого |

Неверный токен и несуществующий ящик неразличимы (`404`).
В этапе 2 отправка в ящик станет анонимной (sealed sender), сейчас требует подписи зарегистрированного устройства.
