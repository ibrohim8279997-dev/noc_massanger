# Этап 1, клиент Android: проверки безопасности

Важно: приложение собрано (`gradle :app:assembleRelease`, 108 МБ, только arm64), но **на реальном устройстве не запускалось**. Ниже статические и модульные проверки. Этап 1 нельзя считать закрытым, пока проверки не повторены на телефоне.

|---|---|---|---|
| 1 | Телефон открыт | Автоблокировка по таймеру 30 с, 1 мин, 5 мин, база закрывается, повторный вход через BiometricPrompt (код: `MainActivity.onStop`) | В коде есть, на устройстве не проверено |
| 2 | Телефон открыт | `FLAG_SECURE`: нет скриншотов, записи экрана, миниатюры в недавних | В коде есть, на устройстве не проверено |
| 3 | Вредоносное ПО | Нет вызовов `Log.*`, `println`, `printStackTrace` в нашем коде; нет работы с буфером обмена | Пройдено (поиск по исходникам) |
| 4 | Вредоносное ПО | `allowBackup=false` в собранном манифесте; компоненты: экспортирована только `MainActivity` и стандартный приёмник profileinstaller | Пройдено (разбор APK) |

## Известные пробелы
- Не проверена связка клиент и сервер вживую (нет устройства/эмулятора); проверены обе стороны по отдельности и совместимость подписи запросов вектором.
- Root-проверки эвристические. Малварь с root их обойдёт.
- Cover traffic, Tor, sealed sender: этап 2.
- Независимый аудит кода по-прежнему рекомендуется.
