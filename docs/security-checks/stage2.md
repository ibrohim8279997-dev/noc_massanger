# Этап 2: проверки безопасности (Tor, cover traffic, ящики, группы)

Запуск автоматической части: `tools/stage2_checks.sh`. Правило цикла: любая находка, исправление, затем все проверки заново с начала.

## Круги
**Круг 1.** Находки:
1. `ServerApi` имел транспорт по умолчанию (прямой): достаточно было забыть указать Tor. Исправлено: значения по умолчанию нет, адрес `.onion` без Tor-клиента отклоняется (тест).
2. Запрос ключей собеседника шёл отдельным HTTP-запросом другого размера, заметным среди слотов фиксированного размера. Исправлено: запрос ключей идёт внутри такого же слота (серверные и клиентские тесты).
3. Тест «удалённый пользователь» показал: при анонимной отправке удалённый пользователь ещё может писать в чужие ящики, пока их не сменят. Не исправляется внутри схемы; смягчено сменой ящиков (ADR-004, п. 1), закреплено тестом.

**Круг 2.** Все проверки заново: ВСЕ ПРОЙДЕНЫ (50 клиентских тестов, 43 серверных, статические проверки).

## По десяти пунктам
| № | Проверка | Результат |
|---|---|---|
| 1 | Весь трафик только через Tor, нет прямых соединений | Код: единственная точка создания HTTP-клиента, нет сырых сокетов; тесты: через SOCKS-прокси, при недоступном Tor нет прямого соединения. **Сниффер на роутере не запускался** (нет устройства) |
| 2 | Нет утечек DNS | Тест: имя уходит прокси необработанным, локальный DNS запрещён. На устройстве не проверено |
| 3 | Tor упал: нет прямого трафика, запасной канал или блокировка | Блокировка проверена тестом. Автопереход на мосты написан, **не проверен** (в контейнере Tor не выходит в сеть: рукопожатие зависает на 14%) |
| 4 | Все пакеты одной длины | Слоты вверх и вниз одинаковы во всех исходах, включая запрос ключей (тесты). Исключения: регистрация, создание ящика, загрузка ключей |
| 5 | Постоянная скорость, в тишине и при переписке неотличимо | Тесты с симулированными часами: интервал строго постоянен в тишине и с трафиком, настоящее заменяет пустое, пустые случайны. Реальную неотличимость в сети Tor не измеряли |
| 6 | Случайные задержки не дают связать пакеты | Тесты: задержки 0–3 с, разные, копии группы шифруются отдельно. Статистический анализ по времени не проводился |
| 7 | Bluetooth | Относится к этапу 4. Аналог для этапа 2: ящики и их id меняются (тест смены ящика) |
| 8 | Ретранслятор удаляет следы | Этап 4. Аналог: сервер удаляет пакеты после подтверждения и по TTL (тесты) |
| 9 | Сервер не пишет IP, ключи, содержимое | Тест реального процесса со всеми конечными точками этапа 2; за Tor источник соединения у сервера всегда 127.0.0.1 |
| 10 | Фаервол сервера | Этап 3 |

## Не проверено здесь
Реальный Tor (в контейнере нет выхода в сеть Tor), запуск на телефонах, Wi-Fi/роутерный сниффер, поведение мостов, расход батареи и трафика.
