# Этап 3: сервер и суперадмин, проверки

Запуск: `tools/stage3_checks.sh` (11 проверок; правило: находка, исправление, всё заново с начала).

## Круги
**Круг 1.** Находки:
1. `audit.sh` неверно разбирал колонки `ss` и принимал за адрес число очереди (код ошибся, найдено проверкой на образцах). Исправлено.
2. Проверка «нет SSH/Tailscale» ловила слова в комментариях и в списке запрещённых процессов (ошибка проверки). Теперь ищет именно установку и включение.

**Круг 2.** Всё заново: 11 из 11 пройдено.

## Что проверено
| № | Проверка | Как |
|---|---|---|
| 1 | Журнал действий суперадмина с его подписями, смена ключа с доказательством владения новым ключом, старый ключ мёртв, нет удалённого пути к токену | серверные тесты + сквозной тест клиента |
| 2 | Сервер работает не от root; БД шифртекст; ключ не рядом с данными; токен только на консоли и не в БД; утеря админа: сброс только физически | реальные процессы под пользователем `noc` |
| 3 | Нет IP, ключей, токенов в выводе сервера | реальный процесс |
| 4 | Фаервол: вход и выход по умолчанию запрещены, наружу только процесс Tor, loopback работает, ни порта 22/53/80/123/443 | два сетевых пространства с настоящими правилами, с контролем до применения |
| 5 | Правила разбираются `nft -c` | nftables |
| 6 | `audit.sh` принимает чистый хост и ловит публичный порт, sshd, tailscaled | образцы |
| 7 | Обновления только через Tor (apt socks5h), SOCKS Tor только на loopback | конфиги |
| 8 | Tor принимает конфигурацию onion-сервиса | `tor --verify-config` |
| 9 | Ничего не ставит и не включает SSH/Tailscale | файлы развёртывания |
| 10 | Подмена человека, смена ключа, все клиентские тесты | тесты |
| 11 | Телефон открыт, потерян, вредонос: защита экрана, нет резервных копий, Keystore требует свежей биометрии, проверка целостности, автоблокировка, нет логов и буфера обмена | статически |

## Не проверено
Фаервол на вашем телефоне (нужны netfilter и root), реальный запуск от `noc` в proot, поведение приложения на устройстве. Независимый аудит по-прежнему рекомендуется.
