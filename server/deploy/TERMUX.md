# Запуск сервера на телефоне

## Вариант А (проверенный путь): Debian внутри Termux (proot-distro), приглашение вида `root@localhost`
Если `pkg` пишет «Cannot run 'pkg' command as root», вы уже внутри Debian, а не в самом Termux.
1. Внутри Debian, из каталога репозитория: `bash server/deploy/linux-setup.sh` (apt, venv, зависимости; в конце `SQLCipher OK`).
2. `bash server/deploy/linux-run.sh`. Первый раз покажет ключ базы: запишите. Затем сервер спросит ключ и напечатает одноразовый токен привязки.
3. `Ctrl-b`, затем `d`: сессия работает в фоне.
4. Чтобы Android не усыпил процесс, в **самом Termux** (не в Debian) выполните `termux-wake-lock`, а в настройках Android поставьте для Termux Батарея → «Без ограничений».
Остальное (адрес, перезагрузка, сброс суперадмина, ограничения) ниже то же самое. Скрипты `termux-*.sh` нужны только для варианта Б.

## Вариант Б: чистый Termux (скрипты `termux-*.sh`, не проверено)

Не проверено на реальном телефоне. Если на каком-то шаге ошибка, пришлите вывод.

1. Установите Termux из F-Droid (версия из Play Market устарела).
2. Получите код на телефон: `pkg install git`, затем `git clone -b ccr-bee63d04-bee79j https://github.com/ibrohim8279997-dev/noc_massanger` (репозиторий приватный: логин и токен GitHub). Либо скачайте ZIP ветки, распакуйте в Termux.
3. `bash noc_massanger/server/deploy/termux-setup.sh` (долго: собирается Rust и нативные пакеты). В конце должна быть строка `SQLCipher OK`.
4. `bash noc_massanger/server/deploy/termux-run.sh`. Первый раз скрипт покажет ключ базы: запишите. Затем сервер спросит этот ключ и напечатает **одноразовый токен привязки**: введите его в приложении при первой настройке.
5. Отсоединитесь от сессии: `Ctrl-b`, затем `d`. Теперь Termux можно закрыть: сервер продолжает работать в фоне.
6. Настройки Android, без них систему будет убивать процесс: Настройки → Приложения → Termux → Батарея → «Без ограничений»; в уведомлении Termux должно быть «Wake lock held».
7. Адрес сервера для приложения: `http://IP_ТЕЛЕФОНА:8443` (оба телефона в одной Wi‑Fi сети). IP: команда `ifconfig` или в настройках Wi‑Fi.

## Что важно знать
- После перезагрузки телефона сервер не стартует сам: ключ базы вводится руками (так задумано, ключ не лежит рядом с данными). Повторите шаг 4.
- Вернуться к консоли сервера: `bash noc_massanger/server/deploy/termux-run.sh` (подключится к работающей сессии). Остановить: внутри сессии Ctrl-c.
- Потеря привязки суперадмина: остановить сервер, `python -m app.cli reset-superadmin` (из каталога `server`, с теми же `NOC_DB_PATH` и ключом), запустить снова.
- Этап 1 слушает все сетевые интерфейсы без шифрования канала. Используйте только в доверенной Wi‑Fi сети. Tor и закрытые порты: этап 2–3.
